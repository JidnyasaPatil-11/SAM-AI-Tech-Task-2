# Digital Clock in C++

## Project Overview

The Digital Clock is a console-based C++ application that displays the current day, date, and time in real time.

The clock displays the time in Indian Standard Time (IST) and automatically updates every second.

## Features

- Displays the current day and date
- Displays real-time IST
- Shows time in HH:MM:SS format
- Automatically updates every second
- Simple console interface
- Exit using Ctrl + C

## Technologies Used

- Programming Language: C++
- Libraries: iostream, iomanip, ctime, thread, chrono

## Concepts Used

- Time and date handling
- Loops
- Output formatting
- Real-time updates
- Thread and chrono

## How It Works

The program obtains the current system time and converts it to Indian Standard Time (IST).

It displays the current day, date, and time and updates the displayed time every second.

## How to Run

1. Open `Digital Clock.cpp` in a C++ compiler or online compiler.
2. Compile and run the program.
3. The current day, date, and IST will be displayed.
4. The clock updates automatically every second.
5. Press `Ctrl + C` to exit.
